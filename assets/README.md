placeholder box — nothing breaks.

## Tips
- Use **.webp** for images (smaller than JPG/PNG at the same quality).
- Square portfolio images: export at 800×800 or 1000×1000.
- Keep each image under ~300 KB for fast loads; the site already lazy-loads them.
